# @swagger-api/apidom-ns-asyncapi-3

`@swagger-api/apidom-ns-asyncapi-3` contains ApiDOM namespace supports following AsyncAPI specification versions:

- [AsyncAPI 3.1.0 specification](https://github.com/asyncapi/spec/blob/v3.1.0/spec/asyncapi.md)
- [AsyncAPI 3.0.0 specification](https://github.com/asyncapi/spec/blob/v3.0.0/spec/asyncapi.md)


## Installation

You can install this package via [npm CLI](https://docs.npmjs.com/cli) by running the following command:

```sh
 $ npm install @swagger-api/apidom-ns-asyncapi-3
```
